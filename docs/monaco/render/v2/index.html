The Story: The Foundry & The Canvas

Traditional web playgrounds suffer from style leakage and DOM conflicts: the code editor's styles interfere with the preview element styles, and heavy IDE bundles slow down DOM reactivity.

Render V2 completely decouples them into two separate browser tabs:

Tab 1: The Foundry (Supplier)

Houses the 3-column Monaco workspace. Transform your data, inspect the JSON AST, and click [Render in Tab 2] to beam the spec across the browser's BroadcastChannel.

Tab 2: The Canvas (Consumer)

A pure, clean room with zero Monaco bloat. Listens silently, parses the incoming spec, and compiles live HTML directly into <body id="app"> using jsonToDom.
