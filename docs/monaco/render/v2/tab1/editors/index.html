The Story: Component Architecture of Tab 1

Tab 1 acts as the **Foundry**: it loads input data, lets you select element molds, compiles the JSON AST, and beams it to Tab 2.

Each column is isolated in a subfolder:

  • Left Editor (Source): Manages columns.json and file input parsing.
  • Middle Editor (Template): Populates live dropdown options dynamically from spec-repo.
  • Right Editor (Output & Broadcast): Compiles the transform and beams payload via BroadcastChannel('keshavsoft-render-1d').
  • Common: Houses shared Monaco AMD initialization and base styling.
