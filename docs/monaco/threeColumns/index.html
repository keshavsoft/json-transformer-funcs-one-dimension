Three-Column Monaco Studios

The 3-column architecture separates the 1D transformation pipeline into three side-by-side concerns: Source Data + Element Template + Compiled Output.

Launch Latest (v3) Monaco Hub Docs

The Story: Why Three Columns?

In one-dimensional transformations, every output element is created by pairing a collection of data objects with an element mold (template). When editing in dual-pane editors, developers frequently lose sight of the template mold while inspecting data.

The Three-Column Studio solves this by placing all three stages in a simultaneous horizontal workbench:

Column 1: Source Data (Array)
Column 2: Template Mold (JSON)
Column 3: Resolved Output (AST)
