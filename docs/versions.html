From Wiring Spaghetti to Single Source of Truth

Each folder below represents a distinct evolutionary milestone. You can click Launch on any version to open its interactive Monaco Editor playground with live tabs (columns.json, template.json, output.json) and test raka, template, and build transformations in real-time.

Milestone 1 Imperative Handlers
v1
Modular Handlers

Separated buttons into dedicated folders (rakaBtn/, templateBtn/, buildBtn/). Each folder imported Monaco models and attached its own addEventListener directly to DOM IDs.

Milestone 2 Declarative Loop
v2
Instruction Bindings

All button folders vanished! Replaced with a human-readable bindings.json and clean actions.js, driven by a centralized container event delegation loop.

Milestone 3 CDN Library (v4)
v3
CDN Delegation (v4)

The local delegation loop was removed entirely. In its place, bindEvents is imported directly from dom-primitive-bindings CDN (dist/v4/min.js) hosted on GitHub Pages.

CDN Delegation (v5)

Upgraded remote package to dist/v5/min.js of dom-primitive-bindings. Retains pure declarative configuration with enhanced event bubbling guards.
